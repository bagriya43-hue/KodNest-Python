# Programming vs Programming Language

## What is Programming?

Programming is the process of creating clear instuctions to solve a problem using a computer.

## What is a Programming Language?

A Programming Language is a formal language used to express programming instructions in a form that a computer can process.

## What is Python?

Python is a high-level programming language or interpreted or hybrit language.

## What is Syntax?

Syntax means the writing rules of a programming languages.

## Programming vs Python?

Programming is a clear instructions to solve a problem. Python is hybrit programming language.
